MailCast: Email to Audio

March 2025

The Intuition

To keep up with the rapidly evolving AI landscape, I subscribed to over 15+ daily newsletters. However, sitting down to read through all of them every single day quickly became too time-consuming. I needed a way to consume this information on the go.

That's how MailCast was born. I built this application to automatically fetch the top unread emails from my account and convert them into engaging, podcast-style audio tracks. Now, I can listen to my daily tech updates anywhere, anytime—turning my commute into a learning session.

Technical Execution

  • Email Integration: Developed a Python pipeline integrating the Gmail API for seamless email retrieval and used BeautifulSoup for robust text preprocessing.
  • Script Generation: Utilized Large Language Models (LLMs) to intelligently parse raw email content and generate conversational podcast scripts.
  • Audio Synthesis: Implemented OpenAI's Text-to-Speech (TTS) API and PyDub to process and output high-quality audio files.
  • Scalability: Built OAuth2 authentication and chunked text processing logic to successfully handle API token limits for large datasets.
