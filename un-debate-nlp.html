UN General Debate NLP Analysis

Accepted: Jan 2026 | BAI'26 Conference

The Intuition

The UN General Debate represents a massive historical archive of global diplomatic priorities. I wanted to see if we could use Data Science to map how the world's "conversation" has shifted in this dacade. By applying NLP to over 4,700 speeches, I aimed to quantify the transition from Cold War-era security concerns to modern priorities like climate change and global inequality.

Technical Execution

  • Data Processing: Cleaned and tokenized a dataset of 4,700+ speeches using Python, NLTK, and spaCy to handle diverse linguistic patterns.
  • Topic Modeling: Implemented Latent Dirichlet Allocation (LDA) and Non-Negative Matrix Factorization (NMF) to identify dominant themes across decades.
  • Visualization: Created histograms, word clouds, and time-series plots to track the rise of sustainability and regional focus variations.
  • Statistical Analysis: Leveraged Chi-Square tests to validate significant differences in keyword usage between different global groups.
