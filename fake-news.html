Fake News Classification

Spring 2025

The Intuition

I have a deep interest in Natural Language Processing (NLP), and I wanted to push my Machine Learning skills beyond standard models by diving into the architecture that revolutionized AI: Transformers.

To truly understand how these models process language, I set out to build an end-to-end pipeline to classify news as real or fake. This project allowed me to get my hands dirty with the entire machine learning lifecycle—from constructing robust data flow pipelines to fine-tuning and retraining a pre-existing DistilBERT model on an entirely new dataset.

Technical Execution

  • Data Engineering: Processed a massive dataset of over 44,000 articles, performing rigorous data cleaning, tokenization using AutoTokenizer, and standardized train/validation/test splitting.
  • Model Fine-Tuning: Utilized the Hugging Face Transformers library to fine-tune a DistilBERT NLP model specifically for sequence classification.
  • Optimization: Leveraged PyTorch with GPU acceleration and implemented mixed precision training (FP16) to ensure faster computation and drastically reduced memory usage.
  • Performance: Successfully achieved an outstanding accuracy of 99.98% on the test set, thoroughly evaluated using confusion matrices and classification reports.
